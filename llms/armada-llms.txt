# Armada Bridge Documentation

> Armada Bridge is a GPU Cloud Management Platform (PaaS) that enables enterprises, neoclouds, and research institutions to manage, provision, and orchestrate GPU infrastructure at scale. It supports bare-metal, virtual machine, and Kubernetes workloads across NVIDIA and AMD GPUs.

## Overview

- [Overview](https://docs.armada.ai/bridge/overview): Introduction to Armada Bridge, architecture, and key concepts
- [Architecture](https://docs.armada.ai/bridge/overview/architecture): Platform architecture and component relationships
- [Key Concepts](https://docs.armada.ai/bridge/overview/concepts): Core terminology and concepts
- [Personas](https://docs.armada.ai/bridge/overview/personas): Admin and Tenant user roles
